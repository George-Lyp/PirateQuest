# PirateQuest

A 2D side-scrolling pirate action platformer, built for the 2026 "My Internet+" (Huilang Cup)
student competition — Software track / Game Development / Theme 2 (2D game).

> Working title: *Pirate's Lost Map*. In-game UI language: English.

## Status

Early development. Current milestone: **M0 — project baseline**
(URP 2D pipeline, input system, player movement). No playable build yet.

## Tech stack

- Unity **2022.3.62f3c1**
- Universal Render Pipeline **14.0.12** (2D Renderer)
- New Input System (keyboard + gamepad)
- uGUI + TextMeshPro

## Run locally (development)

1. Install Unity 2022.3.62f3c1.
2. Clone this repository.
3. Add the folder to Unity Hub and open it.
4. Open `Assets/Scenes/Test_Setup.unity` and press Play.

## Controls (planned)

| Action      | Keyboard   | Gamepad    |
| ----------- | ---------- | ---------- |
| Move        | A / D      | Left stick |
| Jump        | Space      | A          |
| Attack      | J          | X          |
| Throw sword | K          | Y          |
| Dash        | Left Shift | RB         |
| Interact    | E          | B          |
| Pause       | Esc        | Start      |
